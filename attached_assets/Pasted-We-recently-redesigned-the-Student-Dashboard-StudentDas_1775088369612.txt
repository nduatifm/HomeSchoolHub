We recently redesigned the Student Dashboard (StudentDashboard.tsx) and I want the Parent Dashboard and Teacher Dashboard updated to match the same design language and UX philosophy. Use the Student Dashboard as the reference. Here is what to apply:
General layout & structure

Sidebar-driven navigation using hash-based tab switching (window.location.hash) — no inline <TabsList> visible on the page
Greeting header with first name + a purposeful nudge line (not just the date) that reflects the role's context — e.g. for teachers: how many students have pending submissions; for parents: how many tasks their child has due
Tab content rendered conditionally (activeTab === "x") instead of wrapped in a <Tabs> component

Home/overview panel (shown when on the default tab)

A solid bg-primary hero banner with a single bold CTA — for teachers this could be "Review next submission →", for parents it could be the child's next due task
An all-caught-up green panel (bg-green-50 border-green-200) when there's nothing actionable
A "Today's Tasks" or role-equivalent list (e.g. "Pending Reviews" for teachers, "Child's Tasks" for parents) rendered as chunky tappable <button> rows — not <div> rows with a small button inside

Task/action rows

Each row is a full-width <button> wrapping the entire card — the whole surface is the tap target
rounded-2xl, border-l-4 accent, emoji icon on the left, title + subtitle, <ChevronRight> on the right
Color-coded left border cycles through violet, sky, emerald, amber, pink per row index
active:scale-[0.985] press feedback
Overdue items use text-red-500 font-semibold

Class/student cards (where applicable)

For teachers: student roster cards or classroom cards should use the same illustrated SVG banner system from the Student Dashboard's "All Classes" panel. Match the banner to the subject keyword (math → violet symbols, science → emerald flask/atom, art → pink palette, history → amber globe, english → sky open book, default → slate rings)
Cards are <button> elements, rounded-2xl, with a h-24 illustrated banner on top, class/student name bold left-aligned, subject or role label below in matching accent color
Whole card lifts on hover (hover:shadow-md hover:-translate-y-0.5)

What to remove

ColorfulStatCard grids — remove entirely from all dashboards
Inline <TabsList> / <TabsTrigger> visible on the page — navigation lives in ModernSidebar only
Small isolated CTA buttons inside list rows — the whole row is the button

What to preserve

All existing data fetching, query keys, mutations, and API logic — only the UI layer changes
data-testid attributes — keep all of them exactly as they are
Dialog/modal flows (submit assignment, etc.) — keep as-is, just triggered from the new row buttons
Role-specific content that has no student equivalent (e.g. teacher grading tools, parent progress views) — keep those panels, just restyle their containers to use rounded-2xl border cards instead of flat <Card> wrappers
