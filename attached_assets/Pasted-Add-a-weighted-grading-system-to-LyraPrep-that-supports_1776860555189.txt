Add a weighted grading system to LyraPrep that supports separate grading rules per item type across all classroom subjects. This touches four areas of the codebase: item creation, grading policy settings, grade calculation, and grade display.
1. Item type field
Add a required type field to every Assignment and Test creation form. The available types are: Assignment, Test, Quiz, and Project. The teacher selects the type from a dropdown at creation time. Store this as a type column on the gradeable item record. This field is required — the form should not submit without it.
2. Grading policy per subject
Inside each classroom subject (e.g. Grade 5 → Math), add a "Grading Policy" settings panel accessible to the teacher. The teacher defines a weight percentage for each type (Assignment, Test, Quiz, Project). Weights must sum to 100% — validate this inline and prevent saving if they do not. Store the policy as a record linked to the subject with an effective_from date set to the date the policy is saved. Each policy change creates a new policy record rather than overwriting the existing one, so historical grade calculations are preserved. Policy changes only apply to items created on or after the effective_from date — past items retain the policy that was active when they were created.
3. Grade calculation
Calculate a student's overall grade per subject as a weighted average using the active policy for each item. If a type has no graded items yet, exclude it from the calculation entirely but flag it as "Pending" in the grade breakdown — do not count it as zero. If no grading policy has been set for a subject, default to equal weighting across all item types that have at least one graded item present.
4. Grade display
Show the grade breakdown transparently to teachers, students, and parents inside the subject view. Display the overall weighted percentage at the top, followed by a per-type breakdown. Example structure:
Overall: 84%
├── Tests (50%)       → 88%
├── Assignments (30%) → 79%
└── Quizzes (20%)     → Pending
Pending types should be visually distinct — use the amber/warning color token, not red. The overall percentage should exclude pending types from its calculation and display a small note indicating the grade is partial (e.g. "Based on graded items only — Quizzes pending").
